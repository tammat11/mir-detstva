# Оплаты и Telegram-бот на Vercel

Сайт, страница оплаты, панель садика и бот работают на Vercel. Данные и квитанции хранятся в приватном хранилище Vercel Blob.

## Настройка (один раз, можно с телефона)

1. **Хранилище.** Vercel → проект → **Storage → Create → Blob**:
   регион **Frankfurt (fra1)**, доступ **Private**, галочка **«Add a read-write token env var»**.
2. **Переменные.** Проект → **Settings → Environment Variables** → добавьте:
   - `BOT_TOKEN` — токен бота от @BotFather;
   - `ADMIN_KEY` — пароль садика (от 8 символов);
   - `SITE_URL` — адрес сайта, например `https://mir-detstva-sigma.vercel.app` (необязательно — для кнопки «Открыть панель» в боте).

   Проверьте, что там есть `BLOB_READ_WRITE_TOKEN` (добавляется в шаге 1).
3. **Redeploy.** Проект → **Deployments** → у последнего «⋯» → **Redeploy** (чтобы переменные подхватились).
4. **Запуск бота.** Откройте `https://ваш-сайт/api/setup`, введите пароль → «Запустить».
5. **Уведомления садику.** Напишите боту в Telegram: `/admin ваш_пароль`.

> Токен бота храните только в переменных Vercel. Если он попал в чужие руки: @BotFather → `/revoke`, замените `BOT_TOKEN`, сделайте Redeploy и снова откройте `/api/setup`.

## Как это работает
**Родитель** — в боте:
1. «Отправить мой номер» — бот находит ребёнка по телефону (или спрашивает имя ребёнка).
2. Присылает фото, скриншот или PDF квитанции. Если детей несколько — выбирает, за кого.
3. Получает уведомление, когда оплату подтвердили или отклонили. «📊 Мой статус» — оплачен ли месяц.

Без бота можно загрузить квитанцию на сайте: `pay.html`.

**Садик** — `admin.html` (вход по паролю) или прямо в Telegram:
- **Список детей** — имя, телефон родителя, группа, сумма в месяц.
- **На проверке** — открыть квитанцию, выбрать ребёнка и сумму, «Подтвердить оплату».
- **Не оплатили** — «Напомнить всем в Telegram» или по одному.
- **Telegram** — кто подключился; непривязанным — «Добавить ребёнка».
- **Автонапоминания** должникам — 5-го и 10-го числа в 10:00 (Алматы).

## Где что лежит
- `api/` — серверные функции: `app.js` (сайт), `tg.js` (бот), `setup.js` (запуск), `cron.js` (напоминания)
- `lib/core.js` — логика, `lib/db.js` — хранилище
- `vercel.json` — регион и расписание напоминаний
